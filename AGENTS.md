# Snake

The classic snake game from old mobile phones, full screen on Apple TV. A SwiftUI tvOS app with no dependencies.

- `Snake/SnakeGame.swift`: the rules, with no UI. A 30x15 board, the snake wraps around the edges, turns are queued so two quick swipes make a U-turn, and it speeds up as it grows.
- `Snake/GameView.swift`: the screen, drawn as a grid of LCD pixels in a `Canvas`: the score in a 3x5 pixel font, the framed board, the food and the snake (3x3 blocks joined by a line of pixels). It also handles the remote: swipe to steer, click to start or continue, Play/Pause to pause, and Back/Menu pauses a running game or goes back to the Home screen otherwise. The best score lives in `@AppStorage("best")`.
- `Snake/Assets.xcassets`: the layered Apple TV icon and Top Shelf images, generated by `scripts/render-icon.swift`. The LCD colors there match the ones in `GameView.swift`.
- `SnakeTests/`: Swift Testing tests for the rules. `SnakeUITests/`: drives the game with `XCUIRemote` and attaches screenshots.
- `scripts/screenshot.sh` and `scripts/render-banner.swift`: the README's `docs/screenshot.png` and `docs/banner.png`.

## Build and run

Requirements: macOS 15 or later, Xcode 26.

```bash
xcodegen generate                  # after editing project.yml
swift scripts/render-icon.swift    # after editing the icon, also writes build/icon-preview.png
scripts/screenshot.sh              # docs/screenshot.png, from the simulator
swift scripts/render-banner.swift  # docs/banner.png, from the icon layers and the screenshot
xcodebuild test -project Snake.xcodeproj -scheme Snake -destination 'platform=tvOS Simulator,name=Apple TV 4K (3rd generation)' -derivedDataPath build/sim -resultBundlePath build/test.xcresult
xcrun xcresulttool export attachments --path build/test.xcresult --output-path build/shots
```

The tests boot the simulator headless, no window opens. The UI test's screenshots end up in `build/shots`.

To install on a paired Apple TV, find its name with `xcrun devicectl list devices`, then:

```bash
xcodebuild -project Snake.xcodeproj -scheme Snake -destination 'platform=tvOS,name=<Apple TV name>' -derivedDataPath build/tv-device -allowProvisioningUpdates build
xcrun devicectl device install app --device '<Apple TV name>' build/tv-device/Build/Products/Debug-appletvos/Snake.app
xcrun devicectl device process launch --terminate-existing --device '<Apple TV name>' com.flaviocopes.snake
```

## Rules

- `project.yml` is the source of the Xcode project, so edit it and regenerate instead of changing `project.pbxproj` by hand. The version lives in its `MARKETING_VERSION`.
- Keep the rules in `SnakeGame.swift`, free of SwiftUI, and add a test in `SnakeTests` for every rule you change.
- Verify UI changes with screenshots from the simulator, either `scripts/screenshot.sh` or the UI test's attachments.
- Everything on screen and in the icon is drawn in code. Never add graphics, sounds or fonts taken from other games. Nokia's name appears only in the README's Legal section, which says the project isn't affiliated with Nokia. Keep it out of the app, the icon, the docs, the code and the release notes.
- There's no binary release: tvOS can't install apps from a download, so people build it from Xcode, as the README explains.
